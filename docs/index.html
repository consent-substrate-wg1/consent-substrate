How it works

One Ed25519 trust root, two mechanisms. A rules-of-engagement gate holds every agent action to a signed, unexpired scope manifest — deny-by-default, fail-closed, with every allow and every refusal written to a hash-chained audit log. A canary substrate seeds tokens, decoy paths, and decoy endpoints that are indistinguishable from real loot; its chain's first link is pegged to the gate's chain head. Together they form one evidence forest.

Reproduce the evaluation

The full replay is one command, zero network, zero dependencies:

python canary_skill.py --selftest

Because the chain is a pure function of the rule set, a third-party re-run must reproduce the exact chain digest. Divergence is a finding — that's the reproducibility guarantee, not a bug report.
